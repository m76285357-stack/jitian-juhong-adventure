把冒险，放进一张卡。

NFC 卡片或贴纸里只需要存一个游戏链接。写好后，手机靠近卡片，点击系统弹出的链接，即可进入橘红少年大冒险。

这就是要写入的游戏网址

下载二维码 ↓

二维码是备用入口，不支持 NFC 的手机也可以扫码玩。

写卡，只需要三步

  1. 在支持 NFC 的手机上打开写卡工具，例如 NFC Tools。选择写入 → 添加记录 → URL / 链接。请选链接类型，不要选普通文本。
  2. 粘贴上面的游戏网址，选择写入，然后把空白 NFC 卡片或贴纸贴近手机 NFC 感应区，等工具显示成功。
  3. 用另一台支持 NFC 的手机测试：解锁并靠近卡片，点击弹出的链接。确认出现“碰一碰成功”，再点击“开始冒险”。

也可以试试网页直接写卡

支持 Web NFC 的安卓浏览器中可使用。若按钮不可用，请按上面的写卡工具步骤操作。网页只在你点击后请求权限，不会自动读取其他卡片。

首次打开游戏需要联网。加载成功后可缓存到本机，方便再次打开。
